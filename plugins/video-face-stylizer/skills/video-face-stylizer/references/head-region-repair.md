# 补漏与抽查

在整头模式下，用画面定位残留原纹理的时间与位置。coverage 和 review_intervals 是筛查线索：有掩膜不等于完整覆盖，没掩膜不一定有真人漏遮。分割的头发支撑不足也可能发生在误识别的手部皮肤，不能据此自动断言某帧戴帽子。

## 取坐标并检查椭圆

使用插件安装环境的 Python 执行本 Skill 的 `scripts/head_region_grid.py`。路径替换为真实绝对路径，输出使用新文件名；脚本不改原视频、不调用模型、不上传素材。

```text
python "SKILL_DIR/scripts/head_region_grid.py" --input "SOURCE.mp4" --seconds 8 --output "CHECK_DIR/frame-8-grid.png"
python "SKILL_DIR/scripts/head_region_grid.py" --input "SOURCE.mp4" --seconds 8 --box 0.20 0.15 0.32 0.38 --output "CHECK_DIR/frame-8-ellipse.png"
```

默认网格间隔 5%，读出整头（包括帽檐）的归一化左/上/右/下坐标。第二条中的数字只是坐标格式示例，必须根据当前帧重选。蓝色矩形显示参数边界，黄色椭圆显示实际人工掩膜边界；检查帽檐、耳朵在椭圆内，而不是只在矩形内。脚本返回实际解码时间和帧号；变帧率或不精确 seek 时与请求时间核对。

头部运动、转身或大小变化时增加取样点，检查相邻关键帧之间。约半秒可作为首次抽样间隔，快速运动应更密；这不是固定数量或覆盖保证。不要把网格诊断图交给渲染工具当源视频。

## 填写补漏区域

以下仅示范一个已确认没有切镜的 8–10 秒区间，坐标需重新量取：

```json
{
  "coverage": "head",
  "start_seconds": 8,
  "duration_seconds": 2,
  "head_regions": [{
    "start_seconds": 8,
    "end_seconds": 10,
    "keyframes": [
      {"seconds": 8, "box": [0.20, 0.15, 0.32, 0.38]},
      {"seconds": 9.5, "box": [0.35, 0.15, 0.47, 0.38]}
    ]
  }]
}
```

将这些字段合入渲染工具的 request，并提供 input_path 和新 output_directory/output_filename。关键帧须落在所属区域内且时间严格递增；end_seconds 不含在区域内。工具内部裁切仍用源时间；输入若是另存的预切片，时间从该文件起点计算。不同镜头分别建立区域。人工区域为多个椭圆的并集，自动遮罩仍会继续执行。

## 复核与交付

1. 查询原任务到终态，记录 coverage、review_intervals 和实际输出路径；不要用重复渲染查询进度。
2. 对照源片和输出，查看每镜头首/中/末、转场两侧，以及所有可疑区间。短镜头按实际帧取样，不固定向后偏移 0.2 秒。
3. 检查脸部、帽子、发型、耳朵原纹理是否残留，以及宠物、商品、手部、字幕是否被误盖。
4. 只补有问题的区间，按同样位置再次复核。补跑片段若另行拼回，检查接缝、尺寸、帧率及音轨。
5. 交付时区分工具成功、抽查范围与仍未验证的帧。covered_frames 全覆盖只是每帧至少有一个掩膜，不能表述为完整匿名化或下游一定换人。

已有案例的 2.3 秒 CPU 补跑记录为 138 帧人工遮挡、0 帧无掩膜，但事后抽查仍发现帽檐在椭圆外残留。不要把这组计数写成“整头全部合格”，也不要沿用该案例的框坐标。原始素材、任务 ID、机器路径和运行证据保留在任务工作区，不随公开插件分发。
