# 0.2.0 验证记录

验证日期：2026-09-13。Windows x64，Python 3.12.14，RTX 4050 Laptop。

- 自动化单元测试：58 项通过，覆盖参数校验、输出保护、区域时间插值、不透明填充、人物范围和手臂/躯干误检筛选、分割补漏、光流过期/切镜和 Windows 状态文件短暂占用。
- 首次安装：从源码包解压到中文且带空格的目录，移除 PATH 中的 Python/uv，并隔离托管 Python 目录。自动下载 uv 0.12.10 与 Python 3.12.14，安装 53 个运行包，通过包兼容性、模型 SHA256、真实 CPU 模型推理、Numba 编译与 FFmpeg 编码器检查。
- 实际 MCP 启动：测试便携配置的 PowerShell 入口，包含首次依赖准备和后续直接启动。5 个工具可发现，CPU/GPU 输出各 10 帧；按源视频时间覆盖恰好 5 帧，复查区间边界正确，完整解码视频和音频，输入 SHA256 不变。安装目录和输出目录均测试中文路径。
- 人脸检测对比：使用 MediaPipe 官方公开测试图片 portrait.jpg，分别测试近景和将完整图片缩至 160/240/360 像素高后嵌入 1280×720 画面。0.1.0 的三个远景测试均未检出；0.2.0 三个均检出并生成白模，其中最小样本用到了分块分割和局部人脸检测。已人工查看新旧输出。
- 公开图片生成的固定帧率视频：真实 MCP CPU/GPU 各渲染 30 帧，完整解码通过；断开后重连查询、宿主终止后的 interrupted、运行中取消、不发布残片、无效视频和超出片尾时间报错均通过。发现并修复 Windows 短暂读锁导致状态写入失败的问题，重试仅针对状态文件发布，不重做视频任务。
- 会话工作目录中的原片：576×1024、30 fps、13.8 秒共 414 帧，默认整头 GPU 模式完成耗时约 112 秒；人脸网格检出 128 帧（全画面 41、局部检测 87），另有 197 帧使用分割白模，总计 325 帧有遮挡。输出视频及音频完整解码通过。其余 89 帧包含空镜、头部出画和待补漏帧，不能把这些计数当作逐人完整覆盖率。
- 原片视觉抽查：0.5、1.5、3.5、6.5、7.5、9.5、12.5、13.5 秒的可见头部均有白模；4.5、5.0 秒的花束空镜以及 10.5、11.5 秒的躯干/手臂镜头保持原像素。初版误涂背景和手臂的问题已据此修复。完整默认输出仍在约 7.53–8.37 秒之间有若干人物检测缺口，结果明确列入 review_intervals；该段可在看图确认后用 head_regions 补漏，或仅对该有人物的片段关闭 person_filter 后再核对。
