# 钩子选项、重音与音效

按素材选择一种主要开场方式。下面是可复用的创意和表演选项，不是可直接发送给编辑器的 API，也不是必须全部使用的话术。正文、衣服与人物一致性仍按 [内容规则](editorial.md) 验收。

## 开场模式

| 模式 | 开场结构 | 选择依据 |
|---|---|---|
| `source_voiceover` | 约 3 秒全身纯展示 + 另选情绪原声 | 当前纯切片偏好；画面人物无需说话，配音可单独保调提速，详见 [纯切片开头](typography-sound.md#纯切片开头) |
| `offscreen_dialogue` | 画外短问 → 主播短答 → 实拍展示 | 用户选择对话；商品有值得反问、能迅速展示的差异 |
| `emphatic_statement` | 主播一句有重音的陈述或反差设问 → 实拍兑现 | 用户指定强口播，或原片已有更有表现力、依据充分的一句话 |

不必为了使用强调口播模式，再硬加一个画外人或回答。每条视频只选一个主要开场，不把几种强话术连续堆进前几秒。对话与强调口播模式以成片取用 2–4 秒、原速为起点；明确的新要求优先。短问短答中的回答也可以使用同样的重音技巧。

## 先确定继续看的理由

纯展示模式先靠整体穿着和情绪原声吸引注意，不要求把具体卖点塞进前 3 秒。以下问题与兑现规则主要用于对话/强调口播；纯展示模式独立按 [对应规则](typography-sound.md#纯切片开头) 选画面和声音。

当前用户在秋天实片反馈中否定了单独一句“这质感，非——常好！”：只有主观评价，缺少具体关注点。后续默认不把泛泛夸质感作为独立开场；强调口播和自然拖字仍是可选表演方式。

先从已审阅的原片里找一个穿着顾虑、使用场景、可见反差或值得揭晓的细节，再决定怎么说。写清“观众想知道什么”和“原片哪一个动作或细节回答它”。去掉拖字、音效和花字后，台词仍应让人知道要看什么；可套给任何衣服的“质感好、太高级、非常棒”通常需要改写。

在 2–4 秒内只引出一个问题或差异，紧接的正文就开始展示对应证据。可以先给部分答案，留具体做法给原片；不用无内容的“秘密在后面”拖延揭晓。钩子提出领口问题，就先接领口动作，不能先放一串无关织纹。保持已接受正文的内容，若确需调整其开头顺序，先保存快照并只改兑现所需的衔接。

可比较 2–3 个候选，按与本商品的关联、观众收益和现成演示选择。没有证据时缩小承诺；不要为制造痛点自行声称显瘦、不扎、不起球或久穿不变形。画面可证明结构与动作，不能单独证明耐久性或所有人的穿着感受。

## 可选话术方向

下面保留用户给出的方向，并提供更短的成片写法。破折号只表示表演，不是让模型逐字读出的台词。先核对本商品可用的依据，再选文案。

| 方向 / `hook_angle` | 话术与表演示例 | 正文承接和适用依据 |
|---|---|---|
| 穿着顾虑 `wearing_concern` | “怕领口太闷？”“这儿能打开！” | 适合原片确有可打开领口的演示，回答落到具体动作；不从能解扣直接推导显瘦、透气等效果 |
| 细节悬念 `detail_curiosity` | “这扣子只是装饰？”“真能打开！” | 立即接真实解扣或开合展示；仅有扣子静帧时不足以证明功能，不机械套用于装饰扣 |
| 质感细节 `texture_quality` | 从具体结构提问，例如“领口为什么做两层？”；不再单用“这质感非常好” | 保留此标识以兼容旧计划，但需填具体关注点和原片兑现区间。可展示双层结构、织纹或垂坠差异；仅拍一段布料特写不自动构成值得看的钩子，也不证明成分、等级或耐久性 |
| 签收 `delivery_acceptance` | “签收率，特别高！”重点放在“特别”或“高”之一 | 仅在有对应商品/账号、时间范围、统计口径的数据时使用；切片里说过只证明说过，不等于数据已核实。没有依据时换有真实演示支持的穿着顾虑或细节方向 |
| 吸睛 `head_turning` | “这身，回头率特别高！”；作为主观穿搭评价可改“这身，真让人多看一眼！” | 接完整上身、转身或搭配对比；此处按穿着吸睛理解，不自动写成后台回访指标。不虚构真实围观或次数 |
| 复购 `repeat_purchase` | 用户强度参考：“买过的人没有不复购的”；有真实老客记录时短写“买过的老客，又来加购了！” | 需要真实复购记录或反馈，保留适用范围；不把部分老客反馈扩写成“所有人”“没有不复购的”绝对承诺 |
| 推荐 `customer_recommendation` | 用户方向：“买过的姐妹都在推荐”；有反馈时写“买过的姐妹，来推荐了！” | 需要可追溯的推荐内容；不编造评论、人数或买家截图，不把“有人推荐”扩大成人人推荐 |
| 被追问 `asked_about_outfit` | 用户方向：“我听到别人都在问我这件衣服”；有该主播真实经历时短写“我这件，最近总被问！” | 对应主播的真实分享才用第一人称；生成表演不能凭空制造经历。无该经历时改为有真实展示的具体差异或穿搭问题 |
| 反差设问 `winter_style_reversal` | 将“是不是秋冬就是裹着不能显气质”压成“秋冬裹着，就没气质？”；问完接一次“噔噔” | 立即切到同一件衣服的利落上身或搭配结果。让画面回答，不再加一段口头解释，也不靠生成假造商品变化 |

选好一句后，将实际文案写入 `question`/`reply` 或 `statement`。事实性口碑/经营主张逐项记入 `hook_claims`：`text`、`kind`、`evidence_refs`、`scope`、`status`。`status` 可为 `supported`、`needs_evidence`、`subjective`；缺依据时换到可被素材支持的方向，不把等待核实的主张当作可用台词。这里的示例不是当前商品已经具备这些销量或口碑。

## 内容确定后的重音与拖字

- 重音服务于已选的具体内容，可强调动作、差异或关键词；无需每条都拖字。单句只选一个主要拖长点，避免每字都慢。原片中的质感评价可以保留在演示内部，但不再单独抽作默认开场。
- 可先按被强调音节约 0.35–0.7 秒估排，再按实际自然发声调整。这是该音节的总时长参考，不是每处固定增加这么多，也不是硬性验收阈值。其余字保持流畅、尾字完整，整段仍争取 2–4 秒。
- 高情绪来自惊喜、重音、语调起伏和表情；不靠全段高喊、尖声或僵硬逐字念。音色仍是选定主播，衣服和动作仍跟同场参考。
- 台词与表演指令分开。例如在真实开合演示支持下，台词为“这扣子，真能打开！”；表演提示为“带一点惊喜，在‘真’字落重音，流畅说完‘能打开’，不读标点或括号”。是否拖长按实际句长与自然度决定。
- 原片已有合适发声时优先保留；需要生成时把上述指令交给已授权的声音/视频生成入口，并审阅实际输出。原速播放不妨碍演员自然拖音；不默认对已有口型单独拉慢音频或对整段降速，编辑器没有通用逐字韵律控制 API。
- 花字在具体问题、差异或动作关键词处出现并稳定停留，在重音落点做一次轻弹或强调；不持续跳动、不复制一串重复字。字幕用正常字词，拖音不写成连串重复字。

## “噔噔”音效与画面落点

把“噔噔”作为非语言的双击提示音，单独记录成一个音效事件。默认一次、约 0.25–0.5 秒，可跟随实际素材调整；不要让主播把“噔噔”念进台词。放在问句结束或第一处上身展示的切入点，选择一个落点即可，不为等音效延长空拍。

可用已有音效或简单合成的双音提示。记录音效来源、片段、实际 `start`/`duration`、音量和短淡入淡出，按当前 schema 映射到音轨。先保留已符合要求的生成声音，避免又叠一份同样的提示音。音效低于对白、不遮尾字，进入正文后及时收住；以最终混音检查为准，不套固定响度值。

这是声音强调，不要求同时加翻页、整屏闪动或横移。若配全画面装饰效果，仍计入全片至少 1 处、默认 1 处、最多 2 处的转场数量；普通切到真实上身/细节不计入装饰配额。

## 编排记录与验收

在 [流程模板](../assets/workflow-plan.json) 选择 `hook_mode`，按对应 `hook_mode_options` 更新 `hook_structure`、台词和说话人，保存 `hook_selection_reason`。未使用的问答或口播字段留空；不能切到单人强调模式后仍照搬双人轮次。

`hook_attention_reason` 写具体关注点；`hook_payoff` 写原片引用、源区间、可见演示和紧接正文的落点。这些是调用方的规划记录，不是新增工具参数。只有泛泛赞美或尚无兑现镜头时，先修改文案/选片，不以增加拖字、音量或音效替代内容判断。

`hook_emphasis_events` 记录 `text`、`speaker`、`syllable`、`delivery_note`、`estimated_syllable_seconds`；生成或选片后再补 `reviewed_output_start/end`。`hook_sfx_events` 记录 `cue`、`landing`、`asset_ref`、`source_start`、`start`、`duration`、`volume`、`fade_in`、`fade_out`。它们是计划记录，由调用方映射到实际工具；不要把字段原样当成新增 API 参数。

若使用 short-video-prompts，将具体关注点、兑现区间、所选模式、短台词、事实依据、表演指令、真实参考和音效落点一起交接；其默认片长不改变本工作流约 45 秒的整体目标。

验收实际混音和画面：开场是否给出具体关注点、正文首个演示是否回答它，再检查强调字是否自然且完整、音效是否抢话、花字是否落在重音、同一主播衣服是否保持。ASR 可辅助确认台词，不能独自证明拖音和情绪自然；没有试听则如实记录该项未验收。秋天质感强调版曾完成技术制作但被用户否定钩子内容；本次修订不等于新文案已生成或获得认可。
