# 用真实演示剪出商品说明感

在用户要求“像参考片一样剪”、生成只补开头、正文依靠原素材时使用。这里是内容选择与剪辑规划，不是自动识别或新的渲染接口。先看指定参考片再提炼结构；不要机械复制案例时长、商品话术或贴纸。

## 已观察的参考

2026-10-17 用户提供了一条 43.24 秒、720×1280 的竖屏服装视频。本次查看全片每约 2 秒的画面，并加密开头和细节段，共 46 个抽帧点；完成全片本地自动转录，未作人工试听。转录存在服装术语错字，不作为商品事实来源。以下时间为近似区间，不是检测出的全部切点：

| 区间 | 画面与内容功能 | 可以借鉴的编排 |
|---|---|---|
| 0–5.5 秒 | 正面、侧面、背面上身展示，配讲解及局部大字强调 | 先给整体穿着效果，讲解音轨可配合不同展示画面 |
| 5.5–13 秒 | 主播展示袖型、下摆开口、领口/袖口等位置 | 一句具体讲解配一个可见动作，保留动作完成点 |
| 13–19 秒 | 手持同款衣服讲解厚薄与搭配 | 展示实物并承接说明，不用连续大字代替衣服画面 |
| 19–27 秒 | 布料、拼接处和收针的真实近景，短标签与箭头提示 | 细节画面承担证明，标签只指向正在讲的位置 |
| 27–31 秒 | 回到主播上身与触感讲解 | 从细节切回穿着结果，保持句子及声音衔接 |
| 31–43.24 秒 | 手持配色展示，再回到上身效果 | 颜色标签随展示对象切换，最后留出看清效果的时间 |

可见字幕有常规描边台词、重点短词、细节标签、指示箭头和颜色信息，位置与内容相配。不能仅凭抽帧断言所有景别变化都来自后期裁切，也没有依据认定原片整体变速、具体音乐或音效设置。开头的签收/退货类话术属于参考片原有说法，不能移作其他商品的销售承诺。

## 用户对这条参考的修正

用户明确指出开场话术太长、切到重点的镜头偏少。目标是保留这种真实商品演示方式，同时缩短开场、加强正文的重点切换，不原样复制其前半段主讲镜头占比。

- 成片大于 30 秒且小于 60 秒，通常约 45 秒。
- 开场成片取用约 2–4 秒，默认一短问一短答，也可用 [强调口播选项](hook-options.md)；自然语速，台词完整。
- 开场后迅速给第一个强证据画面，再用整体、演示和特写推进其余重点。
- 每个被讲解的核心部位都应有明确对应的画面或手部动作，不只换花字而让画面持续不变。细节必须来自真实素材，缺失时先补料。

45 秒初排可将约 0–3 秒用于短钩子，3–10 秒给最有力的商品演示，10–33 秒交替呈现其他卖点及细节，33–41 秒给穿法/配色或整体结果，末段收住动作与核心回报。该表是起点，按实际完整句子和动作改排，不能凑数填满节点。

## 正文素材够不够

下载数量和秒数仍用于预算与备料，但正文可剪还要检查镜头角色：

- 整体上身：能看清廓形、正侧面或搭配结果。
- 卖点演示：与所选讲解对应的动作，例如开扣、拉袖口、展示下摆。
- 真实细节：需要证明织纹、领口、扣子、缝线等时，有足够清楚的原片。
- 颜色或搭配：只在本次内容需要时收集，商品/颜色与标签一致。
- 声音：完整、可信且适用于本商品的句子，保留影响意思的限定条件。

镜头角色按本片卖点选，不要求每条视频包含所有角色。同一源片可覆盖多个角色，只有几条相似的站立口播也可能覆盖不足。将每个角色标成已有/待查/缺失，附原片 asset ID、源区间和审阅证据。

缺细节时先查同主播同商品的其他切片与已授权回放。没有合适证据就删掉该卖点或报告补料缺口。数字放大不能补出未拍到的织纹或动作；裁切需保留足够清晰度和商品结构，不能把生成的细节当成真实商品证明。

## 先排台词与画面，再装饰

先以完整句意和可见动作重排正文，删去重复、等人、找衣服和无关互动。每个节点必须增加信息或完成演示，不按固定秒数强切，不靠全片加速制造紧凑感。参考片超过 40 秒；short-video-prompts 的 15/25 秒默认值只服务其具体生成稿，不能自动限制这种实拍主体片。

先填写正文剪辑表，再映射至工具：

| 字段 | 含义 |
|---|---|
| output_start/end | 成片中的实际输出时间，依据编辑器时间映射校准 |
| purpose / selling_point | 本段新增信息，以及可追溯的卖点依据 |
| video_asset / source_in/out | 实际原片及取用范围；说明整体/演示/细节等镜头角色 |
| audio_asset / source_in/out | 对应讲解、声音路由与真实源区间，可与画面来自不同片段 |
| framing | 保持原景别，或明确裁切/推近参数及清晰度检查 |
| focus_target / focus_cut_reason | 本次突出哪个部位或动作，为何切入、何时看清；与当前卖点对应 |
| text_events | 台词字幕、卖点短词、箭头或标签，各自的时间、位置和信息职责 |
| cut_reason / boundary_review | 因句意、手势或展示对象变化切换；检查开头、尾句和动作完整性 |

讲到具体部位就尽量展示对应证据。允许口播音轨继续、画面切入同款真实细节；主播可见时检查嘴型，不把别处台词强贴在明显对口型的镜头上。单独音轨需明确起点、持续时间、源偏移和速度，避免源声与附加声重复混响。

先列重点切镜表，再判断节奏：袖型→肩袖/手臂动作，开口→下摆，扣子→开合动作，织纹→真实清楚的布料近景，穿法→对应上身结果。避免一个主讲镜头承担好几个卖点；也不把同一画面反复小幅放大当成新增证据。留足看清细节的停留，换镜时机由新信息、重音与动作决定。

花字按角色分工：常规字幕承接完整台词，重点词只突出一个信息，部位标签/箭头指向证据，颜色或穿法标签识别当前对象。保持主字体和配色统一；有烧录字幕时避让或复用，勿再叠一套相同台词。多数重点镜头直接切换，装饰效果只在大段落边界使用，按 [低频转场规则](editorial.md#6-转场只作段落标点) 检查；重点镜头数量与装饰转场数量分别规划。

## 生成钩子与执行分工

- short-video-prompts 可用于钩子的承诺、问答、参考绑定和提示词；本工作流的正文区间表由素材证据驱动。其当前生成稿合同中的 shots 绑定生成 jobs，不应把原片伪装为生成任务来套合同。
- 钩子交给已授权的视频生成能力，真实人物、衣服、声音仍按 generated-hooks 的来源与审阅要求处理。正文用实际商品素材兑现开头问题。
- video_editer 执行显式源区间、景别、图层、字幕和音轨。现有工具不会自行选好句子、识别最佳卖点、自动跟踪衣服或保证审美。
- GPU 优先、重任务并发 1、排队重试沿用资源策略。混剪完成后重新验尾句、口型、音量、细节可读性、文字遮挡和整片节奏，不能用渲染成功替代内容验收。
