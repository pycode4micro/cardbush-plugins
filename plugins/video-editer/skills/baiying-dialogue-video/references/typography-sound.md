# 花字和声音一起编排

用于当前商品讲解流程的纯切片、生成钩子和混合成片。花字动画与音效作为同一事件设计，不因开头是否生成而改变这项要求。不是每个字、字幕或切镜都配声音；每个重点事件明确选择音效，或记录保持安静的理由。

制作图层前按 [布局与配色](typography-layout.md) 采用透明底文字和整片最多三种主题色，避开平台灰区及原字幕。音效跟随合适位置的文字重音，不为保留声音事件而强塞带底卡片或侵入禁放区。

## 先选落点，再选声音

| 内容与视觉动作 | 可选声音方向 | 落点 |
|---|---|---|
| 痛点词、反差重点，短弹入 | 短敲击、柔和弹点 | 字块出现或重音开始，通常只取一个 |
| 展示结果、揭晓细节 | 短亮音、轻拨弦 | 第一眼看清结果或强调词落下 |
| 透明底部位文字、穿法编号滑入 | 轻滑音、衣料摩擦 | 文字入场，随后安静停留 |
| 段落翻页、穿法切换 | 短纸张翻动 | 翻页动作，与同期花字共用一个声音 |
| 常规台词字幕、同一卖点延续、细节需要专注 | 无 | 保留人声与动作声 |

同片优先少量协调的音色家族，用力度、长短和落点区分职责，避免所有花字同一个机械提示音。可使用用户提供、许可明确的音效或本地程序化音效；记录来源。不要从参考片的混合音轨直接抽取带其他主播台词的声音。

约 45 秒成片可先安排 5–9 个有内容理由的落点，再按实际声音删减；这是可调起点，不是数量指标。2–4 秒钩子一般 1–2 个，正文通常间隔至少 3 秒；相邻关键词、同一组字块分批进入只强化主重音，不逐字响。钩子后首个完整讲解单元先让语句和动作成立，花字保持同一重点，不用连续弹字/音效催促切镜。音效也不要求添加装饰转场。

## 混音和验收

- 短音效通常 0.10–0.35 秒，必要翻页可略长；起音避免尖锐爆点，尾音不跨入下一句。对齐首个可见入场帧或语音重音，偏移以一帧内为起点，按预览修正。
- 先检查原片和生成输出已有的音乐、音效与动作声。已有合适声音就复用，不重复叠加。用户认可正文时，保留主画面、语序和速度，只修改本次授权的声音及花字。
- 人声优先。以同一短窗比较音效和人声的实际电平，可从音效低于人声约 6–12 dB 试起；这是试听起点，不是跨峰值/RMS/LUFS的固定换算。人声尾字、轻声词或密集细节段优先降低或取消音效，不靠降低人声突出花字。
- 人声优先也要让已设计的音效可辨认。不要机械地取极短的轻声、停顿或呼吸窗，再统一降低 12 dB；先结合完整词组附近的有效人声、音效起音与实际混音判断。若被掩盖，逐处调整音量、音色或落点，不靠提高整片音量解决，也不把个案的增益当作通用预设。
- 每个声音记录目标文字/动作、开始、时长、音色来源、增益、淡入淡出，以及已有声音是否重叠。通过独立音轨执行，保留可编辑资源；工具不会自动推断重音或合成合适音效。
- 分开验收“正文素材及人声是否有声”和“每个设计音效是否进入最终混音且可辨”。音轨存在、旧版音轨未变或整片响度正常，都不能代替逐音效检查。按落点比较单独音效与前后完整词组的混音，并在同一播放音量下做有/无音效对照；不对对照样本分别归一化。保留解码/电平证据与试听状态，未试听时不能仅凭指标写成听感已通过。用户反馈听不到后必须重开该项验收。
- 最终混音检查峰值、响度、削波、头尾与相邻句；在成片上重验台词完整和声音落点。ASR 与响度只能支持技术检查，不能认证音色、自然度或审美；未实际试听则如实记录。

## 插件执行与检查记录

使用 `video-editer` 0.3.9+ 时，添加音效显式标注 `audio_track_add(role="sfx", label=...)`，旧音轨用 `audio_track_update` 补标签。音量和淡入淡出也原位更新，保留原音轨 ID、绑定关系与撤销快照；不要为调音量先删后加。`role` 只是用途标签，不自动决定音量或生成声音。

成片或预览成功后，提交 `audio_review_submit(project_id, audio_ids=[...], render_job_id=...)`；默认省略 ID 只选已标记 `sfx` 的音轨。传成功渲染 ID 才核验该版实际输出，避免把后来修改的时间线当作旧成片。通过 `media_job_status` 查结果，失败用 `media_job_retry` 排队重试原请求；改过音轨则提交新检查，不能沿用旧结论。资源等待不重复提交，检查与渲染共用重任务并发 1。

逐处保存 `report_path`、项目版本、成片任务 ID、音轨 ID、信号警告和同音量有/无音效对照。工具还输出去掉该音效后的差值声音；它包含总线限幅相互影响，不等于干净的原始独奏音效。附近非静音小窗统计用于避免只按一个轻声/呼吸窗调得过小，但不识别人声或完整词组。`confirmed` 只说明成片有相应信号；`not_detected`、`inconclusive` 或 `not_testable` 须继续排查，不能直接涨音量解决。低电平/可能掩蔽阈值也不是推荐增益。

每次最多 16 个音效、单个有效长度不超过 15 秒、整片不超过 600 秒；必要时分批检查。没有传成片任务时只检查计划混音，最终输出仍未验收。报告保留 `human_listened=false`，实际试听或用户反馈另记，不能把数值报告改写成“听感通过”。详细工具语义按 [组件发现](components.md) 定位编辑器安装目录内的 `skills/video-editer/audio-and-delivery.md`。旧版本没有这些工具时如实记录能力缺口，可按同一资源锁下的显式对照流程检查，不编造接口。

## 纯切片开头

当前用户选择的形式是 **约 3 秒全身纯展示 + 从另一处选取的有情绪原声**。先让观众看到完整穿着效果，画面人物不需要说话或对口型；开头无需提出具体卖点、标注部位或连续切特写。优先一段自然走动、转身或站姿变化，保留全身和服装廓形；同主播、同衣服的原片优先。正文再进入重点与细节。

声音与画面独立选择并分别记录来源。先查已授权素材中的惊喜、强推荐、反问等完整情绪句，不把面料参数、肩线说明或技术讲解当成情绪钩子。声音可以来自另一段素材，按用户授权来源范围选择，不强行要求与展示取自同一秒。泛泛“质感非常好”曾被否定，不把换声调当成新的创意。主观的夸张表达可用于吸引注意；事实性销量、签收率、复购、退款或效果承诺仍需适用于本商品，不能移用参考片的说法或删掉限定条件。

此模式中画面和正文保持原速；用户已允许 **只对独立配音保调加速**，以完整句子落在约 3 秒内。分别记录 `video_playback_speed`、`audio_playback_speed`、源音区间和输出时长，不能沿用对口型素材必须音画同步变速的规则。先去掉句前等待和无意义停顿，仍过长时可用温和提速；若需要挤压得听不清，换更短的一句，不截断尾字。源画面静音，避免原声与另配声音重叠。

“纯展示、不先讲重点”描述的是画面与内容选择，不能理解成不需要文字或音效。文字跟随实际变速后的完整原声短句，优先在同一组字幕式花字内突出情绪或推荐重音，按视频整幅宽度居中并靠下放在允许区域；不再默认同时保留“小字幕 + 独立大花字”两层。花字与我们添加的普通字幕互斥，避免重复与短暂闪回，细则见 [字幕与花字互斥](typography-layout.md#按片段穿插两种花字)。3 秒开头通常 1–2 处重音配短音效，其余文字安静可读，不逐字响，也不为加花字另剪商品特写。检查动画最大范围，避开脸、服装轮廓、手部及源片烧录文字。该模式先看一段 3 秒样片，再决定是否接回已认可正文；必要时给少量配音候选，画面保持一致以便比较。

此路线不调用视频生成或语音合成，声音和画面均保存实际素材、哈希、源区间与变速记录。它是 [源音频筛选](source-audio.md) 中唯一允许使用无声画面的例外：仅限钩子全身展示，另配音频必须通过检查；不能将此例外延伸为静音正文素材也可另铺音乐。验收分开检查全身展示、完整台词、速度与接缝，并按 [正文承接](editorial.md#钩子后的正文承接) 连续检查开头接入第一段讲解；ASR 和响度不等于听感认可。
