# 花字安全区、透明底与整片配色

适用于本商品讲解流程的纯切片、生成钩子及正文。依据用户 2026-10-17 提供的五张图：图一灰色平台界面区域禁止放新增特效字幕；图二红框是常用候选位置；图三整块浅绿色底板不采用；图四、图五的透明底粗描边字、重点拆色及细下划线作为默认方向。以下记录足以迁移使用，不依赖原截图所在的个人临时目录。新要求优先。

## 先排禁放区域，再选空位

- 平台顶部、底部导航区域、右侧互动按钮列、左下账号/文案区都属于禁放区。按实际视频画布计算，不把播放器外框算进画面；不能把文字贴到底边或右侧按钮缝隙里。
- 经核实已烧录进原片的字幕、直播标题/标识、脸、演示的手以及正在讲解的衣领、扣子、织纹等另列为随时间变化的避让区域。原字幕无论位于上方还是下方，都要保留自己的位置与可读性，不能用新花字覆盖，也不能再叠一套重复台词。
- 优先在上方留白、中部偏左、下方偏左的可用空位放花字；图二红框只是候选范围，并不许可遮住其中的人脸、衣服细节或原字幕。每条花字使用一个位置，不要求三个区域都放内容。同一镜头内稳定停留，不持续漂移追逐人物。
- 无空位时先换候选位置、缩短花字或延后至同一句内可用画面；仍放不下则省略这处可选强调。不能侵入禁放区，也不能用密集切镜、缩小到不可读或大底板遮盖原画面来腾位置。

下面的归一化矩形是从用户示意图提取的保守起点，`[x0,y0,x1,y1]` 相对于实际画面宽高，原点为左上。不是平台官方规范，也不是适用于所有设备/比例的固定坐标；使用前对照目标发布界面和实际画面复核，其他比例重新规划。

| 类型 | 位置 | 近似范围 |
|---|---|---|
| 禁放 | 顶部界面带 | `[0, 0, 1, 0.06]` |
| 禁放 | 底部界面带 | `[0, 0.94, 1, 1]` |
| 禁放 | 右侧互动列 | `[0.84, 0.41, 1, 0.94]` |
| 禁放 | 左下账号及文案 | `[0.02, 0.77, 0.80, 0.94]` |
| 候选 | 上方留白 | `[0.14, 0.09, 0.86, 0.29]` |

| 候选 | 下方偏左 | `[0.03, 0.53, 0.64, 0.69]` |

候选区域扣除禁放区域及该时段原字幕/人物/细节区域后，才是可放位置。额外预留边距，例如先用约画面宽度的 2% 作为检查起点；实际字形、描边、阴影、下划线和装饰都须在可用范围内。动画需检查入场、最大弹跳缩放/倾斜、稳定停留和退场的全部可见占位，不只检查静态文本框。

## 按片段穿插两种花字

先核对文字来源：本项目自己添加的字幕/叠加层可编辑；原素材烧录的字幕、直播标题及标识属于画面本身。不能把前者误当成必须保留的原字幕，导致再叠一套花字。

- **开头钩子优先字幕式花字。** 跟随完整短句，把重点词变色、适度放大、划线或短弹入，其余词安静呈现；整体居中靠下，保留展示画面。
- **正文卖点优先非字幕式花字。** 在上方、中左、左下等经过审阅的其他安全区，用主辅层级、错落拆排、小装饰与短动效突出当前卖点或演示。位置依据人物和商品动作选择，不把它们都塞在底部字幕带，也不要求每个卖点换一次位置。
- **普通讲解保留安静字幕。** 在没有独立花字的时段承接台词，给正文留阅读与观看动作的时间。两种花字按内容穿插，不整片只用一种字幕式样式，也不强行按镜头数、固定比例或每几秒轮换。

两种形式共享本条视频的字体组合、配色、描边及音效家族，但版式和视觉分量可按角色变化。同一时刻只显示一个新增信息组：独立花字出现时隐藏/替换自加普通字幕，不在上下或左右重复显示同一句。一组花字可由主词、辅助字和小装饰等多个图层组成，不能把“一个信息组”误解为只能使用一行字或一个图层。

**居中规则只约束普通字幕和字幕式花字。** 它们以视频整幅宽度的中心线（横向 50%）逐行居中，放在靠下允许区域；不能按剩余安全区居中而整体偏左。右侧按钮使可用宽度变窄时收窄字行或按句意换行，保持中心线。下沿及动画最大范围须在账号文案与底部界面上方，具体高度按画面核验。非字幕式花字继续按其他安全区的构图和演示避让布局，不强制居中或贴到底部。

按完整短句和实际语音组织入退场，互斥检查覆盖入场、停留、退场及相邻帧。按执行器实际帧钟与结束时间语义安排边界；若使用 `[start,end)`，结束值应为下一帧边界，不能提前写成最后可见帧的时间而产生一帧空档。若隐藏后只剩短暂残段，不让普通字幕在花字间隙闪回；按完整语义单元替换或省略重复残段，不增加切镜来制造形式变化。烧录字幕确实存在时仍须避让与去重。

## 透明底文字，不用色块卡片

默认用透明 PNG/SVG 图层或等效文字图层：主词与辅助词分层、字形粗细/大小对比、紧贴字形的深色描边或轻阴影，可辅以细下划线、少量小符号和一次短弹入。图四可借鉴“大词强调 + 小行解释”，图五可借鉴“重点拆色 + 细下划线”。

新增花字不使用整块矩形/圆角色板、条幅、胶囊、气泡底板或宽泛半透明背景；把底板调淡仍属于带背景花字。问句、卖点、穿法编号和结尾都沿用透明底文字形式，不能换角色就恢复卡片。紧贴字形的描边/阴影不是底板，面积不能扩张为遮挡商品的大背景。

调用工具前查看模板实际外观。现有 `callout_*` 的部分预设带固定底板或固定侧边位置，不符合本规则时选可编辑透明叠加层；不要编造 `background=false` 一类工具参数，也不要以模板名称判断是否透明。检查导出资产的 alpha 和实际合成画面。

## 每条单独设计主题，片内保持一致

“统一主题”的范围是一条成片。每条视频可根据服装、场景、账号气质和内容重新选择字体组合、色板与动效风格；不固定为米白橙色、不绑定账号长期使用同一套模板，也不要求从有限的预设清单中选择。案例中的色值只属于该次设计。

整片先锁定一套不超过 **3 种主题对比色**，再设计所有花字；上限针对整条视频，不是单帧或单块文字。字面、彩色描边、下划线、小图标和装饰色点都复用这套颜色，不为每个卖点换色。基础文字可占一色，再配一到两种强调色；例如米白、橙、黄只是一套可选组合，不强制每个账号使用同一配色。

另外统一一种深色中性描边/轻阴影用于可读性，不借描边名义添加新的鲜艳撞色。图四的小色点也须收敛到同一色板；需要表达商品多种真实颜色时优先用文字名称，不为装饰突破主题色上限，也不篡改衣服实际颜色。该上限约束新增设计，不重染源视频或原有字幕。

片内统一选定的字体组合、描边和阴影逻辑、配色及音效家族，具体字块按语气与内容设计：大关键词配小引导词、错落拆排、同词分层进入、局部划线、小符号或短弹入都可变化。统一不等于所有花字同样大小、同一行排版、同一个动画，也不能为了安全区把主词缩成普通字幕。让主词的字号与视觉分量明显高于辅助字；空位不足时缩短文案、换位置或时段，仍不破坏商品展示。图四、图五应借鉴层次与表现力，不只抽取其配色和描边。

每次只强调一个信息，入场后留出稳定阅读时间；不为展示样式连续闪字或增加切镜。原有 [花字音效](typography-sound.md) 及 [连贯性规则](editorial.md#钩子后的正文承接) 继续适用。

## 编排记录与验收

在规划中保存本条视频的主题选择理由、目标画布、界面避让配置、整片色板与字体组合，每个文字事件记录主辅层级、版式/动效、所选位置、同时间段原字幕/人物/细节的避让区域、动画最大可见范围及冲突处理。归一化规划坐标先按画布换算，再映射到工具实际单位；这些记录不是新增 MCP 参数。

逐镜头及动画极值检查：新增字幕/花字互斥；普通字幕及字幕式花字逐行按整幅画面宽度居中、靠下但不侵入账号文案区；正文非字幕式花字按实际安全空位布局；不压灰区、不压原字幕、不挡当前演示、没有带底卡片、所有新增主题色来自同一不超过三色的色板。快切、人物移动或原字幕换行时加密检查；只在画布边界以内不等于通过平台安全区检查。未查看实际叠加效果时保持未验收，不能因 `timeline_validate` 成功就写样式或避让已通过。
