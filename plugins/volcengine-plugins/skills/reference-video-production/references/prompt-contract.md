# 动态覆盖与一致性

先列本次保留/替换项，仅新增项目退出原片强锚定，不每次重写整个参考片。实际请求顺序与素材标签一致。

| 项目 | 默认继承 | 指定后的覆盖 |
| --- | --- | --- |
| 运镜/节奏/主体比例/背景 | 原片真实运动、距离、构图 | 仅修改指定部分 |
| 人物/发型 | 本次合法且获授权的角色来源 | 指定人物控制身份及发型；用户明确只换脸时保留源发型 |
| 商品 | 原款式 | 商品图决定版型、色块、花纹、数量和细节 |
| 台词 | 经理解的原台词结构 | 逐句完整改写，不留“同原片”空白段回退旧品牌/卖点 |
| 字幕 | 明确用户希望的保留方式 | 新台词同步新字幕，或无字幕/后期，不默认添加色块 |
| 音色 | 本次角色来源 | 参考音频仅控制指定角色音色，不提供台词、节奏或背景音 |

## 提示词构建顺序

1. 素材职责：视频1/图片1/音频1各自决定什么、属于谁。商品图模特不成为人物锚点。
2. 保留：镜头高度、距离、主体占比、透视、动作速度、背景和剪辑落点。禁止默认改成静止摆拍或近景大头。
3. 覆盖：身份/发型/商品/台词等的新来源；旧参考不决定被替换项目。输入白模/遮罩不是最终面具/雕塑造型；要求指定角色自然画面，但不承诺无残留。替换发型时预处理范围也必须匹配。
4. 时间轴与逐字台词：覆盖全部轮次，标注角色、画内/画外与停顿。与原台词逐句对照，核对品牌、颜色、材质、数量，不只写开头。按自然语速安排时长，不强塞大量文字。
5. 动作语义：讲口袋指真实口袋，讲袖口展示袖口，讲裤子手势落在裤子。准备、到位、收回连贯，不能把旧动作错套到新台词。
6. 对话：只有当前说话者动嘴，画外问话不要求主角对口型；背景乘客不强行搭话。保持轮次与接话，禁止台词重叠，指定音色不感染其他角色。
7. 结尾：商品展示、最后一句均完整，留自然收势，不末秒硬切另一件衣服补数量，不渐隐遮住未说完的句子。

原片有烧录字幕时，明确用户接受预处理去除/修复后生成，还是让生成接口替换字幕；不能未经说明贴粗色块。无字幕方案明确不生成字幕/标题类文字，同时保留商品合法图案，不笼统抹去所有文字。

优先模型原生同步音频；输入静音独立决定，不从 `generate_audio` 倒推输入处理。事后配音、口型修复、变速是追加方案，须说明限制与授权，不冒充原生结果。

## Blender 预演与外观参考

使用 Blender 配合视频生成时，先选定或按授权生成首尾帧图片、人物/产品/场景参考图。图片确定外观和风格；预演只提供空间、主体整体动线及运镜，不继承占位体的材质、肢体姿态或步态。人物默认适度风格化，避免完全真人化；把这一要求写进实际 `content` 文本，不能只在方案里提及。

多模态参考示例（仅保留实际附带的素材，编号按预览映射替换）：

> 图片1定义主角的三维动画风格、发型、服装和比例，全片保持这一外观，不转为照片级真人面孔或皮肤。图片2、图片3分别表达开场和结尾的构图意图。视频1是 Blender 预演，只决定空间关系、人物整体位置与朝向、运镜和时间节奏。占位体不提供肢体姿态或步态，按本提示词自然生成行走、手势与表情，不复刻滑行和僵硬动作；成片不保留占位体和辅助线。

首尾帧图和预演须先核对构图与空间是否一致。当前模式不允许严格首尾帧与视频参考组合时，不混用角色字段；将图片作为允许的外观/构图参考并说明控制限度。只选择首尾帧模式时，不附带不兼容的视频或音频，也不再宣称成片受预演视频约束。用户明确指定人物风格时，以该风格替换示例中的默认风格。

## 音频锚定必须进入生成提示词

`role=reference_audio` 只标记输入类型，不替代文字说明。要求音色锚定时，把以下约定实际写入 `content` 中的 `type=text` 项，预览核对后原样提交：

- **素材职责**：按预览的实际“音频1 / 音频2”编号绑定指定角色，明确只取音色；音频里的原台词、语速、音乐、环境声不自动成为目标。每个角色各有来源，不把商品图中的人物或视频原声当替代来源。
- **全片声音要求**：要求该角色必须严格使用对应参考音频的音色并跨镜头保持；指定新台词全文，说明台词以本提示词为准。避免另写泛化嗓音描述覆盖指定参考。
- **逐段时间轴**：每段有声台词注明“角色、画内/画外、音色固定为音频N、逐字台词”。多人对话分别标注，无声段无需机械重复；拆成多个生成请求时每份都明确绑定并带入所需音频。
- **末尾禁止项**：不得替换指定音色，不得混用/串用其他角色、参考视频原声或模型默认音色；不得照搬音频原台词覆盖新台词。只有当前画内说话者动嘴，不让其他角色代说。

单角色示例（编号、角色、时间与台词按实际任务替换）：

```text
素材职责：音频1是画面内讲解者甲唯一的音色参考，只控制音色；台词以本提示词为准，不沿用音频1原文。
声音：讲解者甲全片必须严格使用音频1音色原生同步发声，跨镜头保持同一音色。
0–4秒：讲解者甲，画内，音色固定为音频1；逐字说：“这是今天介绍的款式。”
4–8秒：讲解者甲，画内，音色固定为音频1；逐字说：“接下来看袖口细节。”
禁止：替换音频1的指定音色，混入参考视频原声或其他音色，用参考音频旧台词覆盖上述台词，让其他人物代说或同时动嘴。
```

音频若用于音乐、节奏或其他参考用途，按用户要求单独写职责，不套用“只控制音色”。提交前交叉检查每个角色绑定的音频项确实存在，编号与 `media_map` 一致，且 `generate_audio=true`；不能引用未附带的音频或历史请求里的编号。

这些是明确的生成要求，不是接口提供的音色克隆保证。交付前能听辨就对照参考核对音色、串音和跨段一致性；无法听辨则标注未验证。发现偏差只报告并提出修订，不自动重提付费任务。
