# 原始回放 → ASR 时间线 → 纯剪辑

用于自己剪辑时，默认从同商品的原始回放取材，保留停顿、全身展示和完整讲解。不要先下载智能剪辑成品再从中翻找无话展示，也不要因为成品已经够数就停止获取原片。

## 下载入口与来源

1. 查询指定登录身份的实际子账号和商品 ID。`baiying_get_product_videos` 的 `original_fragments` 提供商品原回放及下载地址；按原片分页和 scan_complete 判断已扫描范围。
2. `baiying_prepare_materials(source_policy="original_only", allow_originals=true, allow_intelligent_clipping=false)`。45 秒片默认 `target_count=1,target_seconds=0,min_source_count=1,max_downloads=1,require_audio=false`，只取一段原回放（通常约 10 分钟），在此段完成完整 ASR 和选材。不要自动多取；只有用户明确要求补料才扩大范围。数量足够不代表镜头已合格。
3. `has_existing_clip` / `has_clip_record` 只说明存在关联切片记录，可能仍在处理；不影响原回放本身可下载，不能用这个字段排除原片。不要只找“还没剪过”的原回放。
4. `original_first` 允许原片不足后补成品；`smart_clip_first` 是明确需要百应成品时的兼容路线。纯剪辑默认 original_only，缺料不自动提交百应智能剪辑或回退成品。选款前用户允许择品时可选同主播的原料充足商品；锁定本次一段原片后不自动换款追加下载；网络/登录错误不算缺料。
5. 原片来源不保证干净：交接 `caption_status=unchecked`，必须看画面检查烧录字幕、贴纸和商品身份；来源、原片 ID、文件 SHA256 与 ASR 时间都保留。

## 先转写整份工作素材，再定入出点

排队导入 → `commerce_materials_prepare` / `speech_transcribe_submit` → 成功后 `speech_timeline_get`。长视频按实际 coverage 分窗补齐；超过 600 秒或跨窗完整句要使用工具返回的覆盖范围和重叠窗口，不把未转写区当作无声区。

- 时间线的 `sentence` 是完整候选句，保留源秒数和句子 ID。用 `speech_candidates_get` 读上下文，`speech_range_validate` 校验，再按句子 ID 提交配音/正文候选。
- `asr_uncovered` 仅表示本次转写的字词未覆盖该区间，**不是无声、闭嘴或全身展示的证明**。优先从 2–4 秒以上空档抽帧定位，再看连续画面确认全身、自然动作、无持续说话及字幕相容。漏识别或音乐可能形成假空档；画外主持持续讲话时，画中模特仍可能无话展示。没有 ASR 空档也要检查展示画面，不能据此直接判定缺料。
- 钩子画面与配音是两处独立选区：先比较至少两句完整、有吸引力的原话，再匹配同人同衣的全身纯展示。配音来自其他时间点，不能把展示位置的口播静音冒充无话展示。
- 不提前删掉静音区或整份无音轨视频，可能丢失展示画面。`require_audio=false` 只用于备料保留这些候选；**正文和独立原声仍须逐选区通过非静音检查**。唯一无声画面例外是另配有效声音的展示钩子。
- 原片里已有无话展示也仍需检查：全身构图、人物/衣服、连续口型、烧录字幕不能仅靠 ASR 推断。当前宿主不能真实看/听则保留待验，不能用工具标签伪造通过。

## 合格与淘汰例

合格路径：商品原回放 A 的 70–73 秒是已复查的全身转身展示；同款原回放 A 或 B 的另一处完整情绪原话单独取音；正文用 ASR 绑定的完整讲解及对应细节。例中秒数只是说明，运行时必须取真实工具结果。

淘汰：成品中的人一直说话但把源声静音；原片标记“已剪过”就不下载；ASR 空档直接判定无话展示；把未转写的后半段当静音；正文无声音却铺音乐放行；从智能切片烧录字幕上叠加另一句话。

使用分阶段工具完成约 45 秒、原速、花字/音效/低频转场及验收，其他质量标准沿用主 Skill。此页改变素材来源和选区依据，不降低验收。

## 用户明确改变本次构图时

完整全身仍为默认。如果一段原片没有合格全身展示，先报告真实缺口；只有用户明确同意本次改为无话服装展示，才在钩子审阅/组片之前调用 `commerce_hook_framing_set(framing="garment_display",user_instruction=用户实际原话)`。此例外仅更换本项目的构图检查为 garment_display_visible，不降低同人同衣、不持续说话、字幕相容、独立原声、源音频或真实验收要求；不改写其他项目默认。已拒绝候选不能借此改标签通过。
